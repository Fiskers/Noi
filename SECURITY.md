# Security Policy

## Supported code

This repository tracks the Noi project. Security fixes should be assessed against the latest code in the default branch and the latest release published by the upstream project.

## Reporting a vulnerability

Do not disclose suspected vulnerabilities in a public issue, discussion, pull request, or commit.

- If the vulnerability also affects the upstream Noi project, report it privately to the upstream maintainers through [lencx/Noi security advisories](https://github.com/lencx/Noi/security/advisories/new).
- If the vulnerability only affects changes unique to this repository, use [this repository's private vulnerability reporting page](https://github.com/Fiskers/Noi/security/advisories/new).

Include, when possible:

- the affected version or commit;
- reproduction steps;
- expected and observed behavior;
- security impact;
- relevant logs or screenshots with secrets removed;
- a suggested mitigation.

## Sensitive data

Before submitting a report, remove API keys, authentication tokens, cookies, personal data, and other credentials. Revoke any credential that may already have been exposed.
